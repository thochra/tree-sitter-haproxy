# tree-sitter-haproxy
Tree sitter HAProxy grammar

> NOTE: This version is highly inspired by https://github.com/Ziehnert/tree-sitter-haproxy/blob/main/grammar.js

## Getting Started

```bash
npm install
npm run generate
```

## Testing

To parse a configuration file:

```bash
npm run parse -- path/to/haproxy.cfg
```
